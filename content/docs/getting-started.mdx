# Getting Started

This guide walks you through installing notchnotch and sending your first message. The whole process takes about two minutes.

## Requirements

- **macOS 14** (Sonoma) or later
- A MacBook with a notch (works on non-notch Macs too — the panel appears at top-center)

That's it. No Xcode, no Homebrew (unless you want to use it to install), no developer tools.

## Install

    brew install --cask KikinaStudio/tap/notchnotch --no-quarantine

  </Tabs.Tab>
  <Tabs.Tab>
    1. Download the DMG from [GitHub Releases](https://github.com/KikinaStudio/Notchnotch/releases)
    2. Drag notchnotch to your Applications folder
    3. Open Terminal and run:

    ```bash
    xattr -cr /Applications/notchnotch.app
    ```

    This clears the macOS quarantine flag. The app is not signed with an Apple Developer certificate yet, so macOS would block it otherwise.

    <Callout type="info">
      Don't look for "Allow Anyway" in System Settings — it's buried and unreliable. The `xattr -cr` command is the canonical bypass.
    </Callout>
  </Tabs.Tab>
  <Tabs.Tab>
    If you want to build from source:

    ```bash
    git clone https://github.com/KikinaStudio/Notchnotch.git
    cd NotchNotch
    bash scripts/run.sh
    ```

    No Xcode required. Only Command Line Tools: `xcode-select --install`.
  </Tabs.Tab>
</Tabs>

## Your first conversation

Hover the notch — the chat panel opens with a spring animation. Type something and press Return. A few things to try:

- **"Hello, what can you do?"** — your agent will explain its capabilities
- **"What's in my Downloads folder?"** — it reads your filesystem
- **"Summarize this"** + drag a PDF onto the notch — it extracts and summarizes the text
- **"Remember that I prefer dark roast coffee"** — it saves this to its memory

The braille spinner (`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`) replaces the send button while your agent is thinking. Click it to cancel.

## Permissions

macOS will ask for a few permissions the first time you use certain features:

- **Microphone** — only when you tap the mic button or use voice memos
- **Speech Recognition** — for on-device transcription (nothing leaves your Mac)
- **Accessibility** — for the global hotkey (triple-tap Control). You need to add notchnotch manually in System Settings > Privacy & Security > Accessibility
